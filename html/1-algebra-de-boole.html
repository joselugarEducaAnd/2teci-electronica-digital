1. Álgebra de Boole

Conceptos básicos del álgebra de Boole

George Boole fue un matemático británico que desarrolló el álgebra que lleva su nombre en 1847 y que es la base de la actual electrónica digital.

Variables booleanas

El álgebra de Boole opera con variables booleanas que únicamente pueden tomar dos valores: falso o verdadero. Normalmente esos valores se designan por cero y uno (0 y 1) y representan estados diferentes de un dispositivo, interruptor abierto o cerrado, etc. En los circuitos electrónicos digitales representan si hay o no voltaje. Se pueden utilizar dos tipos diferentes de lógica:

  • Lógica positiva: se asocia el número 1 a un valor alto de tensión y el 0 a un valor bajo.
  • Lógica negativa: se asocia el número 1 a un valor bajo de tensión y el 0 a un valor alto.

En realidad, los niveles altos y bajos no se definen por un único valor de voltaje, sino por una franja o zona en la que podemos considerar que tenemos un valor alto o bajo. Por ejemplo, en el caso de los circuitos TTL (transistor-transistor logic), si se aplica una tensión que varía entre 2,4 V y 5 V se interpreta como un nivel alto, mientras que, si se aplica una tensión de entre 0 V y 0,8 V se interpreta como un nivel bajo.

Operaciones booleanas

A dichas variables booleanas se les pueden aplicar una serie de operaciones del álgebra de Boole, que dan como resultado otras variables también booleanas. Las tres operaciones básicas que se pueden utilizar en el álgebra de Boole son las siguientes:

  • Conjunción lógica (y): el resultado de la operación es verdadero sólo si todas las variables sobre las que se aplica son verdaderas. Por asimilación al álgebra numérica habitual, a esta operación se le denomina producto lógico y se representa mediante un punto (·) al igual que el producto algebraico numérico habitual (A·B). Funciona como el producto numérico normal al identificar verdadero como 1 y falso como 0, es decir:
    • 0 · 0 = 0
    • 0 · 1 = 1 · 0 = 0
    • 1 · 1 = 1
  • Disyunción lógica (o): el resultado de la operación es verdadero con que una sola (o más) de las variables sobre las que se aplique sea verdadera. Por asimilación al álgebra numérica, a esta operación se le denomina suma lógica y se representa por el signo más (+), al igual que la suma algebraica numérica habitual (A+B). Se comporta como la suma numérica normal, salvo en el caso de sumar 1 + 1, cuyo resultado es 1:
    • 0 + 0 = 0
    • 0 + 1 = 1 + 0 = 1
    • 1 + 1 = 1
  • Negación lógica (no): esta operación se aplica sobre una variable lógica y cambia su valor al contrario. Es decir, si la variable era verdadera la cambia a falsa y si era falsa la cambia a verdadera. Esta operación no tiene equivalente en el álgebra numérica habitual y se representa mediante una barra horizontal sobre la variable que se va a negar (A).

Principios del álgebra de Boole

Para definir el álgebra de Boole se parte de una serie de axiomas necesarios, a partir de los cuales se pueden deducir ciertos teoremas. Tenemos que conocer tanto los axiomas como los teoremas para poder operar correctamente y, sobre todo, simplificar las funciones lógicas.

Como existe un principio llamado principio de dualidad, que dice que a toda relación o ley lógica le corresponderá su dual, formada mediante el intercambio de los operadores suma con los de producto, y del elemento 1 con el 0. Por lo tanto, podemos estudiar los axiomas y los teoremas en paralelo para la suma y para el producto lógico, pues son análogos aplicando la dualidad entre unos y otros.

Axiomas

AXIOMA PARA LA SUMA PARA EL PRODUCTO
Propiedad conmutativa A + B = B + A A · B = B · A
Propiedad asociativa (A + B) + C = A + (B + C) (A · B) · C = A · (B · C)
Propiedad distributiva A + (B · C) = (A + B) · (A + C) A · (B + C) = (A · B) + (A · C)
Elemento neutro A + 0 = A A · 1 = A
Elemento complementario A + A = 1 A · A = 0

Teoremas

TEOREMA PARA LA SUMA PARA EL PRODUCTO
Ley de idempotencia A + A = A A · A = A
Ley de dominación A + 1 = 1 A · 0 = 0
Ley de involución A = A
Ley de absorción A + (A · B) = A A · (A + B) = A
Leyes de Morgan A + B = A · B A · B = A + B
